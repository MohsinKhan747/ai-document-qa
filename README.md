# AI Document QA

Ask questions about your documents and get grounded answers with citations.

## Overview

Capstone project: upload PDFs or text files, index them, and query an LLM that answers only from retrieved context.

## Stack (planned)

- Node.js (LTS) + TypeScript
- Next.js (App Router)
- OpenAI-compatible API for embeddings + chat
- Local or hosted vector store for retrieval

## Getting started

Prerequisites: Node.js LTS, Git, and Cursor (or your preferred editor).

```bash
git clone <repo-url>
cd ai-document-qa
npm install
npm run dev
```
